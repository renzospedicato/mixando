Salva e ripristina tutti i moduli

Esporta in un singolo file JSON i dati locali di tutti i moduli Mixando (prefisso mx2::, più i dati propri della Termografia). Reimporta in un altro browser o dopo aver svuotato la cache.

Nel file entrano anche le foto dei punti d'indagine della Mappa, a piena risoluzione: stanno in un archivio a parte del browser e qui vengono salvate, ripristinate e cancellate insieme al resto.

2 Backup (esporta)

Crea un file JSON con tutti i dati di tutti i moduli Mixando. Conservalo in un luogo sicuro.

3 Restore (importa)

Trascina qui un file JSON oppure clicca per selezionarlo
Attenzione: l'importazione sostituisce i dati esistenti dei moduli presenti nel file. I dati degli altri moduli restano intatti.

4 Reset totale

Cancella tutti i dati dei moduli Mixando dal browser. Operazione non reversibile.
